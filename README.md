# Koridor — Online Strateji Tahta Oyunu

Modern, estetik ve tarayıcı üzerinden eşler arası (P2P - WebRTC) oynanabilen online **Koridor (Quoridor)** strateji oyunu.

## 🎯 Özellikler

* **P2P Çok Oyunculu:** Sunucu gerektirmeden PeerJS (WebRTC) üzerinden arkadaşınızla doğrudan oda kodu ile uzaktan oynayın.
* **Yerel / Yapay Zeka Modu:** Aynı cihazda iki kişilik veya tek başınıza pratik yapabilme.
* **Görsel & Ses Efektleri:** Web Audio API ile dinamik ses efektleri ve karanlık tema (dark mode) tasarımı.
* **Akıllı Yol Doğrulama (BFS / A*):** Duvar yerleştirirken iki tarafın da çıkış yolunun tamamen kapanmasını engelleyen kural motoru.
* **Klavye Kısayolları:** Hızlı hamle ve duvar döndürme desteği.

---

## 🚀 Nasıl Oynanır?

1. `index.html` dosyasını tarayıcınızda açın (veya GitHub Pages üzerinden doğrudan oynayın).
2. **Online Oyna** seçeneğini seçin.
3. Oda kodunu arkadaşınızla paylaşın veya arkadaşınızın kodunu girerek odaya katılın.
4. Sıranız geldiğinde piyonunuzu hareket ettirin veya duvar koyarak rakibinizi engelleyin!
